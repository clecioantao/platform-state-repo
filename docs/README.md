# Internal Developer Platform – PoC

Esta documentação descreve a construção de uma PoC de **Internal Developer Platform (IDP)**
usando **Backstage + Argo CD + Crossplane**, com foco em:

- Self-service orientado a aplicações
- GitOps como fonte única da verdade
- Governança e ciclo de vida desde o Day 0
- Ambientes DEV e PROD obrigatórios

Toda a plataforma é reproduzível localmente usando **Kind**.
